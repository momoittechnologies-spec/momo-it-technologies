TRACK 1: Software QA Automation Master Program (12 - 14 Weeks)

Target Roles: Automation Test Engineer, SDET, QA Analyst, API Test Engineer

Module 1: Software Testing Fundamentals & Manual QA (Weeks 1 – 2)

  • SDLC vs STLC, Agile Scrum Framework (Sprints, Epics, User Stories, Standups)
  • Black-Box Testing: Equivalence Partitioning, Boundary Value Analysis, Decision Tables
  • Writing Professional Test Plans, Test Scenarios, and Traceability Matrices (RTM)
  • Defect Life Cycle & Jira Bug Reporting with severities and reproduction steps

Module 2: Core Java for Automation Engineers (Weeks 3 – 5)

  • Object-Oriented Programming (OOP): Classes, Objects, Inheritance, Polymorphism, Abstraction, Encapsulation
  • Java Collections Framework: List (ArrayList), Set (HashSet), Map (HashMap) in depth
  • Exception Handling: Checked vs Unchecked, try-catch-finally, Throw/Throws
  • Apache POI: Reading and writing dynamic test datasets from Excel workbooks
  • Java 8+ Streams, Lambda Expressions, and String Manipulations

Module 3: Selenium WebDriver 4 Deep-Dive (Weeks 6 – 8)

  • WebDriver Architecture & Browser Management across Chrome, Firefox, Edge
  • Advanced Locators: Dynamic XPath axes, complex CSS Selectors, text-matching
  • Interacting with Dropdowns, Checkboxes, iFrames, Alerts, and Multi-Window tabs
  • Synchronization: Implicit Waits, Explicit Waits (WebDriverWait), and FluentWaits
  • Actions Class: Mouse hover, drag-and-drop, context click, and JavaScriptExecutor

Module 4: TestNG & Hybrid Automation Framework Architecture (Weeks 9 – 10)

  • TestNG Annotations, Assertions, Priority, Groups, and Parallel Execution via testng.xml
  • Page Object Model (POM) Design Pattern with PageFactory
  • Building a Data-Driven Hybrid Framework with externalized config.properties
  • Automated failure screenshot listeners and interactive ExtentReports / Allure HTML reporting

Module 5: REST API Automation with Postman & REST Assured (Weeks 11 – 12)

  • HTTP Methods (GET, POST, PUT, DELETE, PATCH), Headers, and Status Code validations
  • Postman Collections, Pre-request Scripts, Tests scripting, and Environment Variables
  • REST Assured (Java): Given-When-Then BDD syntax, Request/Response specifications
  • JSON Path extraction, JSON Schema validation, and Bearer Token authentication

Module 6: BDD Cucumber & CI/CD DevOps Pipeline (Weeks 13 – 14)

  • Behavior-Driven Development (BDD) with Cucumber & Gherkin syntax
  • Maven Build Management (pom.xml, Surefire plugins, clean/install/test goals)
  • Git & GitHub: branch management, commits, pull requests
  • Continuous Integration with GitHub Actions / Jenkins for automated nightly test runs

TRACK 2: Java Full-Stack & Web Development (14 - 16 Weeks)

  • Frontend: Modern HTML5, CSS3, Tailwind CSS, JavaScript ES6+, React 19, Next.js 15
  • Backend: Java 21, Spring Boot 3, Spring Data JPA, Hibernate, RESTful APIs, JWT Auth
  • Databases: PostgreSQL, Supabase Realtime, SQL Queries, Joins, Indexing
