## 📚 TRACK 1: MASTER SOFTWARE TESTING & QA AUTOMATION (12 – 14 WEEKS)
*Target Roles: Automation Test Engineer, SDET, QA Analyst, API Test Engineer*

### Module 1: Software Testing Fundamentals & Manual QA (Weeks 1 – 2)
- SDLC (Software Development Life Cycle) vs STLC (Software Testing Life Cycle)
- Agile Scrum Methodology: Sprints, User Stories, Standups, Retrospectives
- Test Artifacts: Writing Test Strategies, Test Plans, Test Scenarios, and Test Cases
- Black Box Testing Techniques: Equivalence Partitioning, Boundary Value Analysis, Decision Tables
- Defect Life Cycle & Bug Reporting with **Atlassian Jira**
- Test Management with TestRail / Zephyr

### Module 2: Core Java for Automation Engineers (Weeks 3 – 5)
- Java Setup & IDE Mastery (IntelliJ IDEA / Eclipse)
- Object-Oriented Programming (OOP) in Action:
  - Classes, Objects, Methods, Constructors
  - Inheritance, Polymorphism, Encapsulation, and Abstraction
- Java Collections Framework:
  - List (ArrayList, LinkedList), Set (HashSet, TreeSet), Map (HashMap, TreeMap)
- Exception Handling: Checked vs Unchecked Exceptions, try-catch-finally, custom exceptions
- File Handling: Reading & Writing Excel data via **Apache POI**
- Java 8+ Streams, Lambda Expressions, and String Manipulations

### Module 3: Selenium WebDriver 4 Deep-Dive (Weeks 6 – 8)
- WebDriver Architecture & Browser Drivers (Chrome, Firefox, Edge)
- Advanced Element Locators: Dynamic XPath, CSS Selectors, Axes, text-matching
- Handling Web Elements:
  - Dropdowns (Select class), Checkboxes, Radio Buttons
  - Multi-Window, Tab Switching, and iFrame Handling
  - Alerts, Popups, and Browser Authentication Modals
  - Mouse & Keyboard interactions with Actions class, JavaScriptExecutor
- Synchronization Strategies: Implicit Wait, Explicit Wait (WebDriverWait), and FluentWait
- Cross-Browser Testing & Headless Execution

### Module 4: TestNG & Test Automation Framework Architecture (Weeks 9 – 10)
- TestNG Architecture: Annotations, Priority, DependsOn, Groups, DataProviders
- Parallel Test Execution with `testng.xml`
- Designing **Page Object Model (POM)** with PageFactory
- Building a **Hybrid Data-Driven Automation Framework** from scratch:
  - Externalizing test data to Excel / JSON
  - Configuration management with `config.properties`
  - Automated screenshot capture on test failures
  - Rich HTML reporting with **ExtentReports / Allure**

### Module 5: API Testing with Postman & REST Assured (Weeks 11 – 12)
- HTTP Protocols: Methods (GET, POST, PUT, DELETE, PATCH), Headers, Status Codes
- Manual API Testing with **Postman**: Collections, Environment Variables, Pre-request Scripts, Tests tab
- Automated API Testing with **REST Assured (Java)**:
  - Given-When-Then BDD syntax
  - Request/Response specification builders
  - JSON Path evaluation and payload assertions
  - JSON Schema validation
  - OAuth2.0 and Bearer Token Authentication flows

### Module 6: BDD with Cucumber & CI/CD DevOps Pipeline (Weeks 13 – 14)
- Behavior-Driven Development (BDD) with **Cucumber**
- Writing Gherkin Feature Files (Feature, Scenario, Scenario Outline, Examples)
- Step Definitions and Cucumber TestRunner with Plugins
- Build Management with **Apache Maven**: `pom.xml`, dependencies, Surefire plugin
- Version Control with **Git & GitHub**: branching, commits, pull requests
- Continuous Integration (CI/CD) with **Jenkins / GitHub Actions**:
  - Scheduling automated nightly regression suites
  - Email notification on build failures
